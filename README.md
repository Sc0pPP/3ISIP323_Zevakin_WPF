# 3ISIP323_Zevakin_WPF

Стартовый проект WPF-приложения (группа 3ИСИП-323). Содержит пустое главное окно, на его основе собираются дальнейшие работы.

## Технологии

- C#, WPF
- .NET Framework 4.7.2

## Запуск

Только Windows. Откройте `WpfApp7.sln` в Visual Studio и запустите проект `WpfApp7` (F5).
