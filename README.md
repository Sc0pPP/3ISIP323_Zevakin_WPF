# Практическая работа №12 — Конфигуратор автомобиля (WPF)

WPF-приложение для сборки автомобиля и расчёта кредита, группа 3ИСИП-323.

## Сценарий

Пользователь проходит страницы по порядку (с кнопкой «Назад»):

1. **Engine** — модель кузова (`m5e60`, `m5f10`, `m4g82`, `m3g80`) и двигатель (`N50B30`, `N63S63`, `M30B30`, `S54B32`);
2. **ColorDop** — цвет и дополнительные опции;
3. **Costparametrs** — итоговая стоимость с разбивкой: кузов, двигатель, цвет, опции;
4. **Credit** — расчёт кредита по первоначальному взносу и сроку: сумма в кредит и ежемесячный платёж;
5. **Bid** — заявка: ФИО, телефон, почта.

Цена каждой позиции задана прямо в значениях `enum` (`Car.cs`). Ввод проверяется, ошибки показываются через `MessageBox`.

## Технологии

C#, WPF, .NET Framework 4.7.2, навигация через `Frame` / `Page`.

## Запуск

Только Windows: откройте `WpfApp7.sln` в Visual Studio и нажмите F5.
