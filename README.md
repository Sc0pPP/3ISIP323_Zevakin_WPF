# 3ISIP323_Zevakin_WPF — практики по WPF

Практические работы по WPF группы 3ИСИП-323. **Каждая работа лежит в отдельной ветке**, в ветке есть свой README с описанием.

| Ветка | Тема | Технологии |
|-------|------|------------|
| [`pr12`](https://github.com/Sc0pPP/3ISIP323_Zevakin_WPF/tree/pr12) | Конфигуратор автомобиля и расчёт кредита | WPF, навигация по страницам |
| [`pr13`](https://github.com/Sc0pPP/3ISIP323_Zevakin_WPF/tree/pr13) | Интернет-магазин | WPF, Entity Framework, SQL Server |
| [`pr14`](https://github.com/Sc0pPP/3ISIP323_Zevakin_WPF/tree/pr14) | Кинотеатр | WPF, Entity Framework, SQL Server |

В ветке `master` лежит пустой шаблон проекта. Консольные работы (ПР №1–11) — в репозитории [3ISIP323_Zevakin](https://github.com/Sc0pPP/3ISIP323_Zevakin).

## Как открыть работу

```bash
git clone https://github.com/Sc0pPP/3ISIP323_Zevakin_WPF.git
cd 3ISIP323_Zevakin_WPF
git checkout pr13
```

Дальше откройте `WpfApp7.sln` в Visual Studio (Windows, .NET Framework 4.7.2) и нажмите F5.
